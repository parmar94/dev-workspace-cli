# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be respectful, assume good intent, and focus on what's best for the project and its community. Harassment, insults and personal attacks aren't tolerated in issues, pull requests, discussions or any other project space.

## Reporting

Report unacceptable behavior privately to the maintainer, [@parmar94](https://github.com/parmar94), using the contact details on their GitHub profile. All reports are reviewed and handled confidentially. The maintainer may remove, edit or reject contributions, or temporarily or permanently ban contributors, for behavior that violates this code.
